# What is JavaScript
Javascript is a high-level, object-oriented, multi-paradigm (interpreted) programming language that is primarily used for web development. 


## Output in JS
```
console.log("Hello, World!") 
```
## Linking JS to HTML
To link a JavaScript file to an HTML document, you can use the `<script>` tag
Checkout [linking HTML and JS](./examples/linking-html-js/)

## Premitive Data type
- Number           eg: let age = 23;
- String: seq. of characters, enclosed in quotes single or double, eg: let name = "Ankit"
- Boolean: logical type, true or false, eg: let isLoggedIn = false;

- Undefined: value taken by a variable that is not yet defined eg: let name;
- Null: also means empty value
- Symbol: value that is unique and can not be changed
- BigInt: for larger intergers
